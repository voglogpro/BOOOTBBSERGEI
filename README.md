# Шоколадный фонтан — сайт и Telegram Mini App

Трёхэкранный сайт с видео фонтана, переходами по прокрутке, условиями услуги и контактами. Работает как обычный сайт и как Telegram Mini App. Сервер написан на Node.js без внешних зависимостей.

## Запуск локально

Нужен Node.js 18 или новее.

```bash
npm start
```

Откройте `http://localhost:3000`. Порт можно задать переменной `PORT`. Для проверки доступности сервера есть `GET /health`.

## Развёртывание на BotHost

1. Создайте на BotHost приложение **Node.js** и подключите этот репозиторий: `https://github.com/voglogpro/BOOOTBBSERGEI.git`, ветка `main`.
2. Точка входа — `app.js`; команда запуска — `npm start`. Сервер слушает порт из `PORT`, который задаёт хостинг.
3. После запуска откройте выданный BotHost HTTPS-адрес и проверьте воспроизведение видео, прокрутку и кнопку звонка.
4. Для Telegram Mini App укажите этот HTTPS-адрес в настройках кнопки меню бота через BotFather. Сайт также открывается вне Telegram.

Сайт сейчас не содержит текстового Telegram-бота. Его можно добавить позже отдельным процессом или отдельным приложением. Токен бота не кладите в репозиторий: храните его в переменных окружения BotHost.

## Где менять данные

- `public/site-config.js` — название, цена, регион, телефон.
- `public/index.html` — тексты предложения и разметка.
- `public/assets/` — используемые на сайте видео и фотографии.

Форма заявки копирует сведения в буфер обмена; отправки заявок на сервер пока нет. Связь с мастером доступна по кнопке звонка.
