# Шоколадная фабрика Вилевонка — сайт и Telegram Mini App

Четырёхэкранный продающий сайт с видео фонтана, переходами по прокрутке, пакетом услуг и формой, которая отправляет готовое сообщение мастеру в WhatsApp или ВКонтакте. Работает как обычный сайт и как Telegram Mini App. Сервер написан на Node.js без внешних зависимостей.

## Запуск локально

Нужен Node.js 18 или новее.

```bash
npm start
```

Откройте `http://localhost:3000`. Порт можно задать переменной `PORT`. Для проверки доступности сервера есть `GET /health`.

## Развёртывание на BotHost

1. Создайте на BotHost приложение **Node.js** и подключите этот репозиторий: `https://github.com/voglogpro/BOOOTBBSERGEI.git`, ветка `main`.
2. Точка входа — `app.js`; команда запуска — `npm start`. Сервер слушает порт из `PORT`, который задаёт хостинг.
3. При желании включите приём заявок на сайте (см. «Заявки на сайте»).
4. После запуска откройте выданный BotHost HTTPS-адрес и проверьте воспроизведение видео, прокрутку, кнопку звонка и отправку тестовой заявки.
5. Для Telegram Mini App укажите этот HTTPS-адрес в настройках кнопки меню бота через BotFather. Сайт также открывается вне Telegram.

Бот используется только для отправки заявок вам. Токен бота не кладите в репозиторий: храните его в переменных окружения BotHost.

## Заявки на сайте

По умолчанию форма предлагает только WhatsApp и ВКонтакте. Кнопка «Оставить заявку на сайте» появляется, когда сервер может переслать заявку в Telegram-бот владельца. Для этого в переменных окружения BotHost нужны два значения:

- `TELEGRAM_BOT_TOKEN` (или `BOT_TOKEN`) — токен бота от BotFather;
- `TELEGRAM_CHAT_ID` — кому отправлять все заявки (например, владельцу). Можно указать несколько id через запятую;
- `TELEGRAM_CHAT_ID_KRASNODAR`, `TELEGRAM_CHAT_ID_ROSTOV` — необязательно: кому дополнительно отправлять заявки только своего города (мастеру в этом городе).

Как узнать свой chat id: напишите своему боту `/start`, перезапустите приложение и откройте лог — сайт выведет список чатов, которые писали боту.

Каждая заявка также дописывается в `data/leads.jsonl` и выводится в лог, поэтому она не потеряется, даже если Telegram недоступен. Если заявку не удалось переслать в Telegram, посетитель видит просьбу позвонить. Если сервер недоступен, посетитель видит номер телефона и ссылки на мессенджеры.

## Города

У каждого города свой адрес — его удобно ставить в рекламу:

- `/krasnodar` — Краснодар, мастер Ольга;
- `/rostov` — Ростов-на-Дону, мастер Анастасия.

Адреса `/краснодар`, `/ростов`, `/krd`, `/rnd` перенаправляют на основные. Посетитель, открывший главную страницу `/`, сначала выбирает город; выбор запоминается и ставится в адрес. Сменить город можно кнопкой в шапке или в форме. На странице города заголовок, превью ссылки и разметка для поисковиков сразу называют этот город. Список страниц для поисковиков — `/sitemap.xml`.

Кнопка «Договориться» открывает конструктор сообщения: посетитель по шагам выбирает праздник, дату и время, число гостей и место, пишет имя и сразу видит готовое сообщение мастеру. Затем выбирает, куда его отправить:

- «Оставить заявку на сайте» — только если настроены заявки на сайте (нужен телефон);
- «WhatsApp» — открывается чат с мастером города, сообщение уже вставлено;
- «ВКонтакте» — открывается переписка с мастером, сообщение копируется: его нужно вставить и отправить (ВКонтакте не позволяет подставить текст по ссылке).

Каждое нажатие на WhatsApp или ВКонтакте записывается в `data/leads.jsonl` с пометкой канала, а при настроенном боте ещё и приходит владельцу.

Новый город добавляется в двух местах: в `cities` в `public/site-config.js` (имя, мастер, телефон, ссылки) и в `cities` в `app.js` (адрес страницы, название для заголовка и телефон).

## Где менять данные

- `public/site-config.js` — цена, номер счётчика Яндекс Метрики и для каждого города: мастер, телефон, WhatsApp, ВКонтакте и организации-клиенты для блока «Нам доверяют» (`clients`; пустой список скрывает блок). Пустое поле скрывает соответствующую кнопку.
- `public/index.html` — тексты и разметка. Метки вида `%CITY_IN%` в заголовке страницы сервер заменяет на данные города.
- `public/assets/` — видео и фотографии.
- `public/preloader.js` — порядок фоновой загрузки роликов.
- `public/sales.css` — оформление продающих блоков: цены, иконки, форма, экран бронирования и нижняя панель на телефоне.

## Как устроена загрузка

Первый экран открывается, как только готовы его обложка, шрифты и первое видео (обычно за 1–3 секунды, максимум за 4,2 секунды). Главное видео воспроизводится по мере загрузки. Остальные ролики скачиваются в фоне в том порядке, в котором посетитель до них доходит, и воспроизводятся уже из памяти. Пока ролик перехода не скачался, экраны сменяются плавным затемнением. В режиме экономии трафика и при отключённой анимации ролики не скачиваются.
