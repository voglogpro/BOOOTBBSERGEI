# Торговый журнал — Telegram Mini App

Совместный журнал для двух трейдеров. Он работает как Telegram Mini App и как обычный сайт с общей базой данных. Каждый участник входит через Telegram, отмечает состояние, записывает сделки и видит календарь дисциплины. Запись можно оставить личной или показать напарнику.

## Что уже работает

- серверная проверка `Telegram.WebApp.initData` по подписи бота;
- безопасный вход на сайте через Telegram и подписанная HTTP-only сессия;
- автоматическая синхронизация сайта и Mini App по Telegram ID;
- отдельное хранение данных по Telegram ID;
- команда на двух участников с приватным восьмизначным кодом;
- идея дня с режимом (бэктест, демо или реал), направлением, уровнями и условием отмены;
- отдельные недельные идеи по каждому инструменту с фотографиями размеченных графиков;
- связь сделок с недельным планом, отметка соблюдения идеи и P&L по дням недели;
- главный экран «месяц → неделя → день» с отдельным результатом дня и всей недели;
- проверка направления сделки: контртрендовый вход требует подтверждения разворота;
- итог недели с оценкой исполнения, выводом и переходом между прошлыми и будущими неделями;
- дневная оценка настроения, энергии, уверенности и дисциплины;
- пошаговая запись сделки: план и триггер → исполнение → тейк, стоп, безубыток или ручной итог;
- защищённые скриншоты графика до входа и после выхода с превью прямо в ленте сделок;
- сделки со статусом, сессией, сетапом, уверенностью перед входом, ценами, риском, P/L, R, эмоциями и ошибками;
- редактирование прошлых сделок и защита от дублей при повторном нажатии;
- личные и командные записи;
- месячный календарь результатов и настроения;
- параметры проп-счёта и контроль остатка дневного лимита;
- статистика прибыли, винрейта, profit factor, ожидания, просадки, сетапов и дисциплины;
- сравнение уверенности и состояния дня с тейками, стопами, винрейтом и средним R;
- кривая капитала, наблюдения по повторяющимся ошибкам и обогащённый CSV для анализа нейросетью;
- адаптация к светлой/тёмной теме и safe-area Telegram;
- SQLite в постоянной директории хостинга.

## Локальный запуск

Требуется Python 3.11+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

В `.env` для локального просмотра:

```dotenv
DEV_MODE=true
DATABASE_PATH=./data/trader_journal.sqlite3
PORT=8080
```

Запуск:

```powershell
python main.py
```

Открыть `http://localhost:8080`. `DEV_MODE` нельзя включать на публичном сервере.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

Подробное подключение бота и размещение описаны в [docs/DEPLOY.md](docs/DEPLOY.md).

## Структура

```text
journal/            backend, Telegram auth, SQLite и API
static/             стили, клиентский код и иконка
tests/              тесты подписи, базы и HTTP API
docs/DEPLOY.md      настройка BotFather и хостинга
main.py             серверная точка запуска Python
index.html          основная страница Mini App
Dockerfile          однозначный запуск Python-контейнера
```

## Приватность

Приложение не запрашивает номер телефона, пароль Telegram или доступ к сообщениям. Сервер получает только подписанные Telegram данные Mini App. Друг видит лишь записи с видимостью `team` и не может их изменять.
