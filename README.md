# Шоколадный фонтан — сайт и Telegram Mini App

Четырёхэкранный продающий сайт с видео фонтана, переходами по прокрутке, пакетом услуг и формой заявки, которая приходит в Telegram. Работает как обычный сайт и как Telegram Mini App. Сервер написан на Node.js без внешних зависимостей.

## Запуск локально

Нужен Node.js 18 или новее.

```bash
npm start
```

Откройте `http://localhost:3000`. Порт можно задать переменной `PORT`. Для проверки доступности сервера есть `GET /health`.

## Развёртывание на BotHost

1. Создайте на BotHost приложение **Node.js** и подключите этот репозиторий: `https://github.com/voglogpro/BOOOTBBSERGEI.git`, ветка `main`.
2. Точка входа — `app.js`; команда запуска — `npm start`. Сервер слушает порт из `PORT`, который задаёт хостинг.
3. Добавьте переменные окружения для заявок (см. «Заявки в Telegram»).
4. После запуска откройте выданный BotHost HTTPS-адрес и проверьте воспроизведение видео, прокрутку, кнопку звонка и отправку тестовой заявки.
5. Для Telegram Mini App укажите этот HTTPS-адрес в настройках кнопки меню бота через BotFather. Сайт также открывается вне Telegram.

Бот используется только для отправки заявок вам. Токен бота не кладите в репозиторий: храните его в переменных окружения BotHost.

## Заявки в Telegram

Форма на сайте отправляет заявку на сервер (`POST /api/lead`), а сервер пересылает её вам в Telegram. Для этого в переменных окружения BotHost нужны два значения:

- `TELEGRAM_BOT_TOKEN` (или `BOT_TOKEN`) — токен бота от BotFather;
- `TELEGRAM_CHAT_ID` — кому отправлять заявки. Можно указать несколько id через запятую.

Как узнать свой chat id: напишите своему боту `/start`, перезапустите приложение и откройте лог — сайт выведет список чатов, которые писали боту.

Каждая заявка также дописывается в `data/leads.jsonl` и выводится в лог, поэтому она не потеряется, даже если Telegram недоступен. Если заявку не удалось переслать в Telegram, посетитель видит просьбу позвонить. Если сервер недоступен, посетитель видит номер телефона и ссылки на мессенджеры.

## Где менять данные

- `public/site-config.js` — цена, регион, имя мастера, телефон, Telegram, WhatsApp и номер счётчика Яндекс Метрики. Пустое поле скрывает соответствующую кнопку.
- `public/index.html` — тексты, разметка и мета-теги для превью ссылки (`og:image` указывает на текущий адрес BotHost: при смене домена обновите его).
- `public/assets/` — видео и фотографии.
- `public/preloader.js` — порядок фоновой загрузки роликов.
- `public/sales.css` — оформление продающих блоков: цены, иконки, форма, экран бронирования и нижняя панель на телефоне.

## Как устроена загрузка

Первый экран открывается, как только готовы его обложка, шрифты и первое видео (обычно за 1–3 секунды, максимум за 4,2 секунды). Главное видео воспроизводится по мере загрузки. Остальные ролики скачиваются в фоне в том порядке, в котором посетитель до них доходит, и воспроизводятся уже из памяти. Пока ролик перехода не скачался, экраны сменяются плавным затемнением. В режиме экономии трафика и при отключённой анимации ролики не скачиваются.
