# Развёртывание Telegram Mini App

## 1. Подготовить бота

1. Создать бота через `@BotFather` или использовать существующего.
2. Сохранить токен только в переменных окружения хостинга как `BOT_TOKEN`.
3. После появления HTTPS-адреса открыть BotFather → **Bot Settings → Configure Mini App → Enable Mini App** и указать этот адрес.
4. Дополнительно настроить **Menu Button**, чтобы журнал открывался одной кнопкой из диалога с ботом.

Telegram передаёт Mini App поле `initData`. Backend этого проекта проверяет подпись, срок действия и Telegram ID. Значения из `initDataUnsafe` серверу не доверяются.

## 2. Переменные окружения

```dotenv
BOT_TOKEN=123456789:секретный_токен
DATABASE_PATH=/app/data/trader_journal.sqlite3
PORT=8080
MAX_AUTH_AGE_SECONDS=86400
DEV_MODE=false
```

Для закрытого приложения можно указать только ваши два Telegram ID:

```dotenv
ALLOWED_USER_IDS=111111111,222222222
```

Если список пуст, войти сможет любой человек, открывший Mini App через этого бота, но чужие личные данные и команды ему недоступны.

## 3. Постоянное хранение

Каталог базы должен переживать обновления контейнера. Для BotHost используется `/app/data`. Перед переносом или переустановкой сделайте копию файла `trader_journal.sqlite3` вместе с файлами `-wal` и `-shm`, предварительно остановив приложение.

## 4. Команда запуска

```text
python main.py
```

Приложение слушает `0.0.0.0` и порт из `PORT`. Проверка состояния доступна по `/health`.

## 5. Проверка перед публикацией

- `DEV_MODE=false`;
- HTTPS работает без предупреждений сертификата;
- `BOT_TOKEN` отсутствует в GitHub;
- Mini App открывается именно из Telegram;
- каждый участник видит только свои личные записи;
- код команды передан только другу;
- каталог базы является постоянным.

Официальная документация: [Telegram Mini Apps](https://core.telegram.org/bots/webapps).
